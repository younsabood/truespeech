# Security Policy

## Supported versions

Security fixes are directed at the latest code on the `main` branch. Maintainers may also issue fixes for a published release when practical.

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting page](https://github.com/younsabood/truespeech/security/advisories/new), if it is enabled for this repository. Include the affected version or commit, the impact, and a minimal reproduction when safe to share.

Do not disclose an exploitable issue in a public issue or pull request before a fix is available. If private reporting is unavailable, contact the repository maintainer through the contact information on the [GitHub profile](https://github.com/younsabood).
