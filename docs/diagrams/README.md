# Diagram sources

The `.mmd` files are English Mermaid sources for the library architecture and algorithm diagrams. They are compatible with draw.io's **Arrange → Insert → Mermaid** command and can also be rendered by Mermaid tools.

| Diagram | Coverage |
| --- | --- |
| `files-and-apis.mmd` | Workspace layout, modules, and public entry points |
| `encoder-algorithm.mmd` | DSP flow for one 240-sample frame |
| `dll-and-wav.mmd` | DLL state lifecycle and WAV writing path |
| `function-map.mmd` | Public functions and internal encoder helpers |

For the written design and public return values, see the [architecture guide](../architecture.md) and the [API reference](../api.md).
